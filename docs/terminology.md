Public contracts use implementation-independent terminology.

Internal provider, product, vendor, deployment, database, and infrastructure
names must not appear in public schemas, APIs, examples, or documentation.



| Public term         | Meaning                                                 |
| ------------------- | ------------------------------------------------------- |
| Device Gateway      | Device protocol and connectivity boundary               |
| Fleet Engine        | Location, trip, and fleet-processing capability         |
| IoT Runtime         | Digital twin, attributes, and automation capability     |
| Identity Provider   | Authentication service                                  |
| Event Bus           | Internal event transport                                |
| Integration Adapter | Replaceable connector to an external or internal system |
